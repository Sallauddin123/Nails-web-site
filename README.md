# Project N — Website

Press-on nails for every Indian moment. Handmade in Bangalore.

A single-page, interactive brand website: swipe-to-save sets, paint-your-own nail, vibe-check quiz, catch-the-nails game, nail instrument, physics nail jar, spin-the-vibe wheel, fit finder, and a secret disco mode (type `sakkath`).

## Files

```
index.html     the whole website (HTML, CSS and JavaScript)
images/        photos and favicon
README.md      this file
```

No build step. Libraries (GSAP, Matter.js) and fonts load from public CDNs.

## Publish free with GitHub Pages

1. Create a new repository on GitHub (for example `project-n-website`).
2. Click **Add file → Upload files**, drag in `index.html`, `README.md` and the `images` folder, then **Commit changes**.
3. Go to **Settings → Pages**. Under **Source**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/project-n-website/`.

To use your own domain, add it under **Settings → Pages → Custom domain** and point your domain's DNS to GitHub Pages.

## Before launch

- Replace placeholder prices shown in [brackets] and `[₹ PRICE]`.
- Replace "Project N" with the final brand name.
- Swap stock photos for your own product shoots.
- Connect the WhatsApp sign-up, bag and Nail Club to a real backend or store (Shopify, etc.). They are front-end demos right now.
